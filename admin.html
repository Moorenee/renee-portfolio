FREE FIREBASE SETUP IN 3 QUICK STEPS

  1. Go to console.firebase.google.com and click Create a project (e.g. renee-portfolio).
  2. In your project menu, click Build → Firestore Database → Create Database. Choose Start in test mode (this permits reading and writing).
  3. Click Project Overview Gear Icon → Project settings. Scroll down to Your apps, click the Web </> icon to register a web app, and copy the firebaseConfig object. Paste it in the box above and click CONNECT & AUTO-SAVE TO CLOUD!

Firebase's Spark plan is 100% free forever for personal portfolios. Once connected, every edit in this Studio auto-syncs to the cloud and updates your live portfolio for any visitor on any device!
